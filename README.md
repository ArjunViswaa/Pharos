# Pharos

A marketplace where learners book paid 1-on-1 sessions with verified mentors.

Named after the Lighthouse of Alexandria — one of the Seven Wonders of the Ancient World — that guided sailors safely to port for over 1,600 years. Pharos guides learners through the fog of career decisions to the shore of expertise.

## Stack

- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Database:** MongoDB (Atlas)
- **Auth:** JWT + bcrypt
- **Payments:** Razorpay

## Getting started

```bash
npm install
npm run dev
```

This boots the Express API on `http://localhost:5000` and the Vite dev server on `http://localhost:5173`.
